口径法则

笔数口径：评分笔数等于出厂面行数，一评分一行，不合并同一挂单的多条评分。

两半口径：每条评分只属于「已回复」或「未回复」之一，两者之和等于评分笔数；未回复数由出厂面直接给出，不由本页相减。

覆盖率口径：回复覆盖率＝已回复笔数÷评分笔数（保留四位）；评分笔数为零时出厂面给的是空值，本页印破折号，不印 0.0。

平均口径：平均时效只取已回复的评分，未回复的评分不进任何汇总，因此不会被算得更快。

中位口径：中位数只取已回复的评分；笔数为奇数取正中一项，偶数取中间两项的均值。

极值口径：最快与最慢都只取自出厂面的已回复集合；无已回复时印破折号。

时刻口径：最近回复时刻取已回复评分的最大回复时刻；最久未回评分时刻取未回复评分的最小评分时刻；两者互不替代。

行口径：一条评分「已回复」当且仅当回复时刻与回复编号同时非空；时效由评分时刻与回复时刻两枚存盘时刻复算，与出厂面逐行相等，未回复行的时效是空值而不是 0。

排序口径：已回复行按时效从慢到快排在前面，同一时效按评分号升序；未回复行排在后面，按评分时刻升序再按评分号升序。

作用域口径：市场作用域不带卖家账号；卖家作用域只含该卖家的评分，前缀合法的账号若没有评分则得到诚实空信封。

时效条口径：条宽是本行时效相对本作用域已回复最大值的宽度，不是任何份额，也不是评分好坏；未回复行不画条。

定性口径：本页是开发者 API 市场的服务挂单读数，不是投资建议，也不构成对卖家服务质量的裁决。
