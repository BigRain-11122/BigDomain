口径法则

法则一：月份数等于月行数，评分笔数等于月行笔数之和，且等于最后一月的累计评分。

法则二：月行是从首个评分月到最后一个月的连续网格，中间无评分的月份照实印零行，其平均星级与回复覆盖率印破折号而不是 0.0。

法则三：平均星级是全作用域池化均值（总星数除以总笔数），不是月均值的均值。

法则四：五桶直方图（5★/4★/3★/2★/1★）逐月相加等于该月评分笔数。

法则五：低星笔数是 2★ 与 1★ 之和。

法则六：回复覆盖率的分母是该月评分笔数，无评分月份为未定义（破折号）。

法则七：峰值月取首个评分笔数最多的月份，全部为零时印破折号。

法则八：累计评分是单调累加器，最后一月的累计值等于信封评分笔数。

法则九：买家数是去重计数，可以小于月行买家数相加；页面不按笔数反推买家。

法则十：市场作用域从不与自身对标（市场平均为空）；卖家作用域带市场池化平均作为参照，其他卖家数据不会漏入。

法则十一：宽度条横向比较各月评分笔数，是宽度不是份额；零行不画条。

法则十二：开发者 API 市场是服务挂单面，不是投资建议。
