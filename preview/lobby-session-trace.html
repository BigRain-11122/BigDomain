What the text cap does

An over-cap send is refused: the client sent 4000 characters and the server answered E_TEXT_TOO_LONG instead of broadcasting a shorter line, so no text is silently lost. The spec names the code and its payload (AC-S24), the gate console answers the same input with 413, and the same cap applies to idea.submit.
