口径法则

账户数等于落盘买家块数；每个买家块与市场块都带出厂面的完整键集，缺一即拒渲。

逐账户：净支出 = 毛支出 - 已退，且成交笔数 = 净成交笔数 + 退款笔数。

逐账户：开发者分成 + 平台分成 = 净支出；两边都是整数，不留小数尾差。

逐账户：挂单次数与成交笔数分开计，退款不减少已经发生的挂单。

逐账户：在用关注数不超过关注总数；取消关注不抹掉历史。

逐账户：评分笔数为 0 时平均星级为未定义（印破折号），不得写成 0.0。

逐账户：平均星级落在 0 到 5 之间；越界即判负。

逐账户：有成交才有首笔与末笔时刻，且首笔不晚于末笔；无成交账户两枚时刻皆为未定义。

市场总览行是逐买家按列相加的算术和，不是去重后的市场计数；市场平均星级按评分笔数加权。

买家编号一律以 usr: 开头；同一账户在本页只出现一次。

分成条只表示开发者分成占净支出的宽度；净支出不为正时不画条。
