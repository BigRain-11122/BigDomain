## 一、准入判据四项（先于参数定案·缺一=黑箱·禁空泛律）

1. **确权=收益开关**（gv 标准 2）：分成资格以确权为前置——**AA 登记制登记在册+署名完成才计分成**（ugc 管线 adopted→署名位 named 同源·AC-U12）；未确权=零分成；**违规追回**：搬运/刷量/作弊/违禁内容=取消资格+追回已发分成（协议条款·§四.3）。激励池准入=**零粉丝零付费门槛+过安全初审（msgSecCheck 前置闸）+1 件合格共创作品**（对标视频号 100 粉低门槛获客面·更宽）。
2. **三公示**（gv 标准 1）：分成比例〔恒代币计·学 YouTube 透明度**形式**·55-60% 法币口径锚不照搬〕+结算周期+起兑点——三缺一=黑箱（数值全 [needs-CEO]·§二.1）。
3. **三不可协议条款**（gv 标准 3）：不可退款/不可转让/不可兑换现金——原文级写进用户协议法律文本层+**充值页常驻**（§四.1·对标 Steam 钱包条款协议层同构·非宣传口径）。
4. **合规四件套**：AIGC 生成标识+msgSecCheck 前置闸+非投顾 disclaimer+法币/代币两域隔离（判据 AC-I7~I10·§六）。

## 三、公示面（透明度纪律）
- 公示位置：分成比例/结算周期/起兑点=创作者中心常驻页+用户协议附录；参数公示表=代币页常驻（获取产出率+消费定价+调价公告历史行）。
- 公示/结算文案面一律过 msgSecCheck 前置闸（大厅闸同源·闸未接线=拒启 `E_GATE_OFFLINE` 纪律引用·零新闸代码）；AIGC 呈现=§五.7 全呈现面标识律。
- 分成公示页/结算单/代币页三面 disclaimer 常驻（§四.4）。

## 四、协议面（用户协议条款库·设计态原文级——上线前法务定稿〔BLUEPRINT §十一〕）
1. **三不可条款**（gv 标准 3）：「代币为平台内消费型虚拟权益，**不可退款、不可转让、不可兑换现金或任何法币**；无现金价值（no cash value）、不可用于交换（not exchangeable）。」——**充值页常驻提示**（一切购买/充值入口呈现面·非折叠）。
2. **确权条款**：「用户就其共创作品主张分成权益的，以平台采纳登记（AA 登记制）+署名完成为前提；未确权不计分成。」
3. **追回条款**：「以搬运、刷量、作弊或发布违禁内容等违规方式获取的分成与代币，平台有权取消资格并追回。」
4. **非投顾 disclaimer**（常驻三面）：「代币与分成均非投资品、非证券、无任何收益承诺；策略结果=历史回测研究展示，不构成投资建议。」
5. **调价公告条款**：「平台调整代币获取产出率或消费定价的，按 T1 否决窗流程提前公告（有日期的调价）。」

## 五、红线与不做清单（Non-goals）
- 现金出口/提现/兑换法币=**判负留痕不设计**（BLUEPRINT §五.4 生死线·R-user-value-paths 结论 4 留痕在案）。
- 不发币不融资不证券化；不碰法币结算（BigCompute 唯一出口·引用不复制）。
- **零新代码件零新 schema 零新 API**（管道全引用·本件=分配层结构设计）。
- B 端/达人档现金出口后置设计（gv 标准 4「推测·预留」）=**不立项**（远期另呈批·禁提前设计）。
- 参数数值不越权定档（[needs-CEO]·AC-LP4 先例）。
