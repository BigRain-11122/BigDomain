## 三、建设内容（FUNNEL-LOOP v1 规格）

**载体**：寄宿本司既有 OSLoop（iteration_loop v2 已就位·S4U·零新进程族·零新计划任务）——漏斗环=OSLoop 每日轮内置步（FUNNEL-STEP）+独立可跑 CLI（`src/sandbox/funnel/funnel_daily.py`·同 reconcile_daily 形制）。范式律：环的形状由业务定（引流线索→分发→订单→流水=商业化漏斗四段），每轮自检「推进哪条业务哪个指标」。

**四环串联（每日一轮）**：
1. **环 1 引流线索扫描**：扫描线索收件箱（`state/funnel/inbox/leads/*.json`）→ SQLite append-only 线索台账（lead_id 幂等+域初分类）；零线索=诚实空账行（预商业化阶段=常态·候流量态）。
2. **环 2 共创任务分发**：当日新线索→域关键词路由（game/quant/media/life/city/platform 六域·BLUEPRINT §五补 UGC 路由表正典化）→分发台账；无匹配=unrouted 诚实归档（不丢弃）。
3. **环 3 订单簿记**：订单收件箱（`state/funnel/inbox/orders/*.json`）→订单台账（order_id 幂等）；真实订单=0 时=空账诚实行+沙箱测试订单面跑通管道（收款门 CLOSED 律不破——簿记=记账非收款）。
4. **环 4 代币流水台账**：流水收件箱（`state/funnel/inbox/flows/*.json`）→流水台账（flow_id 幂等·grant/spend 双式）→日账三面（当日发放/当日消耗/存量）+勾稽恒等（存量==累计发放−累计消耗）。
5. **收口日账 rollup**：四环计数+环比（对前一日 rollup）+好坏一行+定位律自检行（`business=commercialization-funnel metric=<四环计数>`）→落日账表。
6. **质量闸（交易合规检·预商业化轻量档）**：门禁词表（BLUEPRINT §五.8 词族·适用面=对用户呈现面口径）扫描日账呈报面 JSON——命中=gate FAIL（fail-closed·阻断当日环呈报）+证据留痕；AIGC 标识面=日账常驻行（非投顾风险提示常驻律同源·预商业化档=标识行存在性检）。

**三不自动化（红线·母案三不+本司护栏合流）**：①收款/上线动作=收款门 CLOSED 律不变（商户号物理件）②账号域=永不代办 ③合规介入点=发布前（2026-10-18 CEO 合规阶段门控令：内部跑零介入·环内扫描=自验面非合规审查面）。

## 四、验收判据（预注册 AC-FN1..FN7·先于代码·AC-FN 前缀全仓零占用实锚 2026-10-19）

- **AC-FN1**（四环串联+确定性）：同一输入收件箱+同一日期参数连续两跑（各自独立全新 SQLite），日账 rollup JSON 序列化逐字节同一（零骰子·零墙钟读取·日期=参数注入）。
- **AC-FN2**（环 1 诚实空账+分类）：零线索收件箱→零计数诚实行+台账零行（不报错不虚报）；有线索→每线索恰一行+域初分类三形（game/quant/other）。
- **AC-FN3**（环 2 路由）：分发台账按六域路由；无匹配域线索=unrouted 诚实归档行（不丢弃）。
- **AC-FN4**（环 3 幂等+空账）：同 order_id 两跑→订单台账恰一行；零订单=空账诚实行。
- **AC-FN5**（环 4 三面+勾稽恒等）：日账三面（发放/消耗/存量）+存量==累计发放−累计消耗恒等（跨日累计正确性）；同 flow_id 两跑→恰一行。
- **AC-FN6**（质量闸 fail-closed）：注入门禁词的日账→gate FAIL+命中词清单留痕；净面→gate PASS 零命中。
- **AC-FN7**（日账+定位律）：rollup 必含四环计数键+定位律自检行+好坏一行（缺任一=判负）。

**环级验收（母案口径·≤10-31）**：引流线索环+订单簿记环 72h 自续（连续 3 日 `qa/funnel-daily-YYYYMMDD.log` 在盘+crash-free）+RUNNER 接线（reconcile_all.py 套件收录 AC-FN 面）+日进化班（转化数据日账入 state log 每日一行）。
