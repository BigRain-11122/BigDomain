## 一、城市 24h 慢直播运营 SOP（有人值守轮班制落地形态）

> **〔平台政策风险注·封禁级·常驻节首——本注为一切慢直播运营动作的前置硬约束〕**
> **无人值守挂播=平台严禁**（patrol-4 E2③+BigCompute risk-register E1·BLUEPRINT §四 直播形态一在册注记）：原案「城市 24h 慢直播·无人值守推流」**禁止以无人值守形态落地**（CEO 令「不然直播间被封」）。落地形态=**有人值守轮班慢直播**；开播策略（时段/形态/挂载）一律以 **BigCompute 风控**为准（本司引用不越权改）。

### 1.0 分工面（同号口径 D-20260924-08 引用）

| 面 | 归属 | 本件边界 |
|---|---|---|
| 直播账号（每平台唯一号） | BigStream 资产面（管号+内容运营） | 本司零开号零管号（账号域=CEO 物理件·永不代办） |
| 开播执行（排期/形态/购物车挂载） | BigCompute 直播运营部 | 本司供给转化件规格，不排班不开播 |

| **直播间转化件供给（购物车/入城钩/共创玩法）** | **本司（BigDomain）** | 本 SOP 主责面：转化件规格+检查表+收账回流 |

### 1.1 开播前检查（每日开播前·值守人执行）

1. **推流源**：FluxVerse 城市画面采集链路连通（画面帧率/音轨/分辨率核对）——画面源=FluxVerse 实况（引用不复制）。
2. **AIGC 生成标识（生死线·源头带）**：推流角标「AI 生成」在画面内叠加（或导播台片头标识）——**标识从源头带，不依赖后期补标**（BLUEPRINT §五.7：直播画面全呈现面显著标注）。缺标识=禁止开播。
3. **非投顾风险提示常驻面**：直播间贴片/滚动条带「历史回测研究展示·非投资建议·不承诺收益」常驻（BLUEPRINT §五.1 三面之一：直播间面）。缺=禁止开播。
4. **购物车转化件**：19.9 算力包挂载正确（SKU/价格/入城钩跳转链路）——入城资格=首笔付费即「出生证」（§四 C-0）。
5. **值守排班**：当日值守人到位（有人值守硬律·见节首注）；无人值守排班=禁止排。
6. **msgSecCheck 状态**：弹幕/UGC 入口内容安全闸在线（未接=直播间弹幕面禁开·§五.3「未接内容安全=大厅/直播间禁上线」）。
7. **应急演练快查**：kill switch（停播/购物车下架）触点可达（见 §二）。

### 1.2 值守巡检（在播期间·巡检节奏以 BigCompute 风控口径为准）

- 巡检点：画面/AIGC 角标/风险提示贴片三面在位 + 弹幕内容安全闸零漏检 + 购物车链路健康 + 观众转化事件回流（world-events）。
- 记录面：巡检节拍内一行记录（时点+三面在位 Y/N+异常注）——发现异常→按 §二分级处置，**先处置后记录不倒置**。
- 弹幕互动（居民回应）=BigLife 本地 LLM 面（零 token 服务器律：生产面永禁跑 LLM——居民台词由城内引擎供给·直播面只呈现）；居民台词呈现=AIGC 标识随台词气泡带（§五.7③）。

### 1.3 事件处置（在播期间）

按 §二 封禁级风险应急面分级执行（本节不重复表——统一口径单源：判据源单点律·integration-deepening-spec §四）。

### 1.4 下播收账（每日下播后）

1. **素材回流**：高光事件切片→BigStream 素材池（自动剪辑智能体消费·模板=BLUEPRINT §六）；CityWatch 截图即带 AIGC 标识（源头带·禁裸奔出域）。
2. **事件回流**：弹幕/打赏/连麦/购物车成交行为→world-events（环A 用户行为入城·脱敏 ID 化——integration-deepening-spec IF-7 事件方言缝）。
3. **台账一行**：当日直播时段+值守人+转化件成交数+异常处置记录——入司内台账（收账面引用）。
4. **代币口径**：打赏→代币纯内循环（§四直播变现：不提现不外流·§五.4 三不可）。

## 二、封禁级风险应急面（风险分级+五场景）

### 2.0 风险三级分级表（AC-SD3b 四列口径）

| 级 | 触发判据（例） | 第一响应 | 升级路径 | 记录面 |
|---|---|---|---|---|
| **P0 封禁级** | 平台风控预警/限流/封禁通知；违禁内容漏网已外泄；msgSecCheck 全量故障 | 立即停损：停播/下架购物车/关闭弹幕入口（kill switch·§2.4）·证据留存（截图/日志/事件号） | **CEO 直报**（P0 1h 修正窗口径参照禁待令）+HQ-FEEDBACK P0/P1 行 | state.json log 一行+HQ-FEEDBACK 一行 |
| **P1 事故级** | 断流>5min；AIGC 标识缺失局部面；非投顾越界话术出现（喊单/荐股类）；支付下单失败簇发 | 修复或降级（fail-closed 优先·§2.5）·受影响面关闭 | 呈报 CEO（P1 只呈批不执行） | state.json log+日清 P-32 |
| **P2 波动级** | 单笔支付失败；单条违禁弹幕漏网未扩散；画面卡顿 | 值守人按 SOP 单点处置 | 司内自决（L0 面） | 巡检记录行 |

### 2.1 场景一：直播间被封/平台预警

- 触发：平台通知/流量断崖/功能禁用征兆。
- 响应：①立即停推流（源头停·不换号续播——换号规避=加重量级违禁·禁）②证据留存（封禁通知原文/时点/在播画面截图）③账号恢复动作=BigStream 资产面+CEO 面（本司不代办·呈报）。
- 升级：P0 直报 CEO+HQ 行；复盘进 SOP 修订（本件 §四 呈批面不越权重写策略——开播策略归 BigCompute）。

### 2.2 场景二：断流/推流链故障

- 触发：画面黑屏/卡死/音画不同步>巡检阈值。
- 响应：①值守人 1min 内确认源（推流端/网络/采集链三查）②>5min=P1 事故级（§2.0）③恢复后补 AIGC 角标与风险提示三面再复播（恢复≠免检）。

### 2.3 场景三：msgSecCheck 故障（内容安全闸）

- 硬律（BLUEPRINT §五.3·SD2 §六降级九条引）：**闸未接线或运行中故障=大厅/直播间弹幕面 fail-closed 禁开**——不自造降级口径，降级动作全引 `docs/spec/integration-deepening-spec.md` §六。
- 响应：①弹幕入口即时关闸（fail-closed）②追查 API 状态（账号域物理件=CEO 面·本司不代办）③恢复后放行+漏窗期内容人工复核通道补查（§五.3 人工复核）。

### 2.4 场景四：内容事故（违禁漏网/AIGC 标识缺失/非投顾越界）

- 违禁漏网：涉事内容下架/撤流+留存样本+msgSecCheck 词库复核（词库面司内可自决更新=数据件面）。
- **AIGC 标识缺失**（生死线§五.7）：发现即停呈现面（直播角标/UGC 落地物/居民台词面）→补标→复核全呈现面清单后才恢复。公开素材已出域缺标=召回请求+P1 呈报。
- 非投顾越界（喊单/荐股/收益承诺出现）：发言面禁言梯度（UGC spec 处置梯度引）+涉事话术下架+**平台呈现面措辞全检**（三面常驻提示在位复核）——被认定非法投顾=直接死（§五.1 前提级）。

### 2.5 场景五：支付/账本异常

- 触发：下单失败簇发/回调异常/对账脚本 reconcile 差异非零（token-ledger-spec reconcile 八查/pay 六查·沙箱在册）。
- 响应：①支付面降级=fail-closed（暂停下单入口·不拒付已成交）②对账差异定位（对账脚本现役件复跑）③账本不可手改（双式账本+库层触发器执法在册·差异走登记修正件）④资金出口面=BigCompute（D-20260924-09 收口·本司呈报不动资金）。
- kill switch 总表（§2.1/2.3/2.4/2.5 引用点）：停推流｜弹幕入口关闸｜购物车下架｜下单入口暂停——四开关位置与触发人在 SOP §1.1.7 开播前核对。
