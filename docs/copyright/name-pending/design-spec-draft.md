## 三、运行环境

运行环境（派生自 import 面实测·ast 解析全清单零手写）：Python 3，标准库自足为主体（数据层 sqlite3、账本/合规/会员等核心面 stdlib-only）。真实第三方依赖按模块派生如下：
- (root)：blind_watermark, cv2, numpy
- lobby：websockets
- pay：cryptography
- ugc：ahocorasick
- watermark：PIL, blind_watermark, cv2, numpy
（上述依赖为各专项面所用：水印嵌水面用 OpenCV/numpy/blind_watermark/Pillow，大厅共创 WebSocket 面用 websockets，UGC 前置预过滤用 pyahocorasick，微信支付 v3 真实通道签名/加解密用 cryptography——均列入软著运行环境如实声明。）
数据层：sqlite3 标准库（单写者、append-only、幂等键）。
部署形态：本地沙箱（docker-compose / 直跑），对外部署 gated on bootstrap 物理件（服务器/域名/备案/商户号）。
